4 — Suggested implementation

Phase 1 (one small commit): give the existing AccentColor colorset appearance variants — light = Oslo mørk blå #2A2859, dark = Oslo blå #6FE9FF — and swap the welcome/splash black for Oslo sort #2C2C2C. Because every button, link, tab tint, favourite/boost fill and donate heart reads that one colorset, the whole app re-skins itself with no code changes.

Phase 2: semantic colours — donate heart and notifications tint → Oslo rød, success states → grønn family, warnings → Oslo gul. These are 3–5 call-site tweaks, all flagged in the icon audit.

Phase 3 (later, optional): a Settings → Appearance "Theme" switcher (Oslo / Mastodon classic / maybe an Oslo lys beige "paper" theme using the beiges) once a paid TestFlight audience exists and there's a reason to offer choice. Until then, one coherent identity beats a settings option nobody has asked for.
