App icon & splash screen — options

Rendered from your actual assets at real proportions (rounded square approximates the iOS icon mask). These are real pixel previews to choose among — whatever you pick lands in one to three files.

App icon (AppIcon.icon)

A. Current — glyph on black
What ships today (16,16,16 = solid black). Neutral, but reads as "no design"; dark-mode home screen blends the icon into the wallpaper.
B. Glyph on Oslo sort
Same shape on warm black (#2C2C2C): slightly lifted off dark wallpapers, but still very muted.
C. Glyph on mørk blå
Clear brand: white glyph on deep navy (#2A2859). Stands out on both light and dark home screens.
D. Gradient navy → black
The most modern feel: diagonal gradient from #2A2859 to black. Matches Xcode-26 icon trends; pairs beautifully with dark splash.
E. Light, navy glyph
White for light-mode users: dark-navy glyph (#2A2859) on near-white background. Best if you later want a light "paper" theme.

Splash screen (UILaunchScreen)

S1. Current — black + full lockup
Black background + square glyph/wordmark lockup, as shipped. A bit busy; the lockup is dense at splash size.
S2. Quiet — Oslo sort + glyph only
Just the small icon glyph centered, on warm black. Feels cleaner and matches an icon-led identity.
S3. Gradient navy + glyph
Navy-to-black gradient (deep at top) with a small white glyph. Matches icon option D as a coherent pair.
S4. Light paper + dark glyph
Oslo lys beige background + dark-navy glyph. A day-mode splash, pairs with icon option E and a light app theme later.

Recommendation

Icon D + Splash S3 as the modern default — the diagonal navy→black gradient with white glyph is where the Oslo identity meets current iOS conventions, and the splash variant echoes the same gradient so launch feels like a continuation, not a switch. If the gradient proves fussy inside Xcode's .icon format, Icon C + Splash S2 is the solid fallback (flat navy, glyph-only splash). Icon E + Splash S4 is the pair to keep warm for a later "light/paper theme" — it is a bigger design decision (welcome screen and default surfaces would want to follow), so park it until the colour work resumes.
